# 人間関係の認知バイアスチェックアプリ

人間関係で「自分は嫌われているのでは」と感じるときの、拒絶への不安や受け取り方の傾向を振り返るシンプルなセルフチェックです。

## 特徴

- 10個の質問に5段階で回答し、合計スコアを表示
- スコアに応じて「高警戒ゾーン」「平均ゾーン」「フラット・ゾーン」の3段階でフィードバック
- 事実と解釈の分離、代替仮説、気持ちのラベリングなどの振り返りのヒントを表示
- HTMLファイル1つで動作し、サーバーや外部ライブラリは不要
- スマートフォンやタブレットにも対応
- 回答はブラウザー内でのみ処理され、送信・保存されません

このチェックは診断や医療的な評価ではありません。スコアは回答を振り返るための目安としてご利用ください。

## 使い方

1. `index.html` をブラウザーで開きます。
2. 10個すべての質問に「1. 全く当てはまらない」から「5. 非常に当てはまる」までのいずれかで回答します。
3. 「結果を見る」を押してスコアとフィードバックを確認します。

## GitHub Pagesで公開する

1. リポジトリの **Settings** を開き、**Pages** を選択します。
2. **Build and deployment** の **Source** で **Deploy from a branch** を選択します。
3. ブランチに `main`、フォルダーに `/ (root)` を指定し、**Save** を押します。
4. 公開が完了すると、同じ Pages 設定画面にサイトの URL が表示されます。
