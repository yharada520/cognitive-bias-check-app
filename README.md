# 人間関係における認知バイアスチェックアプリ (Cognitive Bias Check App)

人間関係において「自分は嫌われているのではないか」と感じてしまう認知の癖（拒絶懸念や敵意帰属バイアス）を数値化し、客観視するためのシンプルなWebアプリケーションです。

## 特徴
- **10の質問による自己評価:** 日常の人間関係に関する10個の質問に5段階で答えることで、認知の歪みをスコア化します。
- **視覚的なフィードバック:** スコアに応じて「高警戒ゾーン」「平均ゾーン」「フラット・ゾーン」の3段階で結果を表示します。
- **具体的な対策の提示:** スコアが高かった場合、心理学・認知行動療法のアプローチ（事実と解釈の分離、代替仮説の立案、ラベリング）に基づいた具体的なアドバイスを表示します。
- **1ファイル完結:** サーバーサイドの処理を必要とせず、`index.html` 1つで動作します。
- **レスポンシブ対応:** スマートフォンやタブレットなど、画面サイズを問わず快適に操作できるデザインです。

## 使い方
1. 本アプリの公開URL（GitHub Pages等）にアクセスします。
2. 10個の質問すべてに対し、「1. 全く当てはまらない」から「5. 非常に当てはまる」のいずれかを選択します。
3. 「結果を見る」ボタンをクリックすると、総合スコアと現在地のフィードバックが表示されます。
